# ☕ Logspresso

A personal coffee pod tasting journal, migrated from `Logspresso.xlsx`. Set this note as your **Obsidian homepage** (Settings → Core plugins → make sure "Files" starts here, or use the community "Homepage" plugin pointing at `README`).

## 🗺️ Vault map

- **[[Flavour Library]]** — the master database of every pod flavour known (124 flavours across 7 brands). This is where you add a new flavour or collaboration the moment you spot it, before you've even tasted it.
- **`Pods Tasted/`** (folder) — one page per flavour you've actually tasted (18 so far). Each page carries its category info up top and a running table of tasting sessions below, so you can log the *same* flavour again each time you prepare it differently (black, with milk, iced, etc.). Also holds [[Pods Tasted/New Pod Page|New Pod Page]], the starting layout for a newly tasted flavour.
- **[[New Flavour Row]]** — copy-paste row format for adding a flavour or a collaboration to the [[Flavour Library]] the moment you spot one.

## 🔁 Your workflow

1. **Spot a new flavour or collab** (in a store, online, a gift) → add a row for it in [[Flavour Library]] under the right Brand/Line section. No page needed yet.
2. **Taste something for the first time** → create its page in `Pods Tasted/` from [[Pods Tasted/New Pod Page|New Pod Page]], fill in the category info, log the session, then go back to [[Flavour Library]] and turn its name into a `[[link]]` + mark it ✅.
3. **Taste it again, prepared differently** → open its existing page in `Pods Tasted/` and add another row to the Tasting Sessions table. Nothing to duplicate — one page per flavour, many sessions.
