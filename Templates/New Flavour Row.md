 Quick copy-paste snippets for adding to [[Flavour Catalogue]].

### Regular flavour

Add under the right **Brand → Line → Collection** section (create the section if needed):

```
- <span class="roast-dot medium"></span> **Name** — *Taste profile* `Cup Size · Intensity` <span class="tried-badge"></span>
```

`roast-dot` can be `light`, `medium`, `dark`, `very-dark`, or `flavoured`. Add `<span class="tag decaf">DECAF</span>` and/or `<span class="tag organic">ORGANIC</span>` after the meta code block if either applies.

### Collaboration / limited edition

Same row format, filed under its own **Brand → Line** section using the collab/drop name as the Collection — then copy the same line into the [🤝 Collaborations & Limited Editions](../Flavour%20Catalogue.md#-collaborations--limited-editions) round-up section too:

```
- <span class="roast-dot medium"></span> **Name** — *Taste profile* `Collab or Drop Name · Cup Size · Intensity` <span class="tried-badge"></span>
```

Once tasted, follow the steps in [[Flavour Catalogue]] to turn the plain-text name into a `[[link]]`, add `tried` to its badge span's class, and create its page in `Tasting Log/` using [[New Tasting Log Entry]].
