# Flavour Library

This is the master database of every coffee pod flavour in the collection — tried and untried. It currently tracks **124 flavours** across **7 brands**, of which **18 have been tasted** (linked below, and detailed in the `Pods Tasted/` folder).

> [!note] How this links together
> - A flavour name that's a **clickable link** (e.g. [[Voltesso]]) has its own page in the `Pods Tasted/` folder — click through to add a new tasting session.
> - A flavour name in **plain text** hasn't been tasted yet. Once you taste it, create a page for it (see below) and it will automatically show up as a link here.
> - ✅ = tasted at least once · ☐ = not yet tried

## ➕ Adding a new flavour you've spotted

Found a new pod at the store, or a new online listing? Add a row for it under the right Brand/Line/Collection section below (create the section if it's a brand-new line), using this template (also kept as [[New Flavour Row]] for quick copy-paste):

```
| Name | Collection | Cup Size | Intensity | Roast | Taste Profile | Decaf | Organic | ☐ |
```

You don't need to create a page for it yet — plain text is fine until you actually taste it.

## 🤝 Adding a collaboration / limited edition

Collabs and limited drops (e.g. *Starbucks by Nespresso*, *Blue Bottle x Nespresso*, festive/seasonal releases) are still filed under their **Brand → Line** section like any other flavour — just use the collaboration's name as the *Collection*. They're also rounded up in the [Collaborations & Limited Editions](#-collaborations--limited-editions) section below so they're easy to spot. Add the same row there too when you log a new one.

## 🎯 Once you've tasted it

1. Create a new note in `Pods Tasted/` named exactly after the flavour (e.g. `Pods Tasted/New Flavour.md`).
2. Copy the layout from any existing pod page (frontmatter block + Tasting Sessions table) — or use [[Pods Tasted/New Pod Page|New Pod Page]].
3. Fill in the category details from its row in this library.
4. The name will now resolve as a link automatically wherever it's mentioned in this vault.
