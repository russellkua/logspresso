Quick copy-paste snippets for adding to [[Flavour Library]].

### Regular flavour

Add under the right **Brand → Line → Collection** section (create the section if needed):

```
| Name | Collection | Cup Size | Intensity | Roast | Taste Profile | Decaf | Organic | ☐ |
```

### Collaboration / limited edition

Same row format, filed under its own **Brand → Line** section using the collab/drop name as the Collection — then copy the same row into the [🤝 Collaborations & Limited Editions](Flavour%20Library.md#-collaborations--limited-editions) round-up section too:

```
| Name | Collab or Drop Name | Cup Size | Intensity | Roast | Taste Profile | Decaf | Organic | ☐ |
```

Once tasted, follow the steps in [[Flavour Library]] to turn the plain-text name into a `[[link]]` and create its page in `Pods Tasted/` using [[Pods Tasted/New Pod Page|New Pod Page]].
